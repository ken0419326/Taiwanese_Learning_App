## Readme

This is the readme file for Group 8 on selected file and source code submitted for Milestone 4 of term project.

### Source code

The source code of the developed system, O̍h Tâi Bûn, is located in **Source Code** folder. The documents regarding the development environment setup, **README.md**, is located under **Source Code** folder as well.

### Activity diagram

Activity diagram for user of the system is **Activity Diagram.jpg** in this folder

### Entity-relationship models

The EER diagram of the entity-relationship models is **EER Diagram.png** in this folder

### Product backlog

The product backlog with mostly user stories are presented as **Product Backlog.png** in this folder

### Task board

The task board by the end of the development of the current system is shown by **Agile Taskboard.png** in this folder

### Status report

The status report at the end of this stage can be viewed in **Status Report.pdf**

### Unit test

The API unit tests of the system are done using JavaScript with the help of Postman platform. The code used in tests are saved in json file under the **Unit Test** folder. The tests are stored by category and the json files can be opened with Postman.

Note that the correctness and executability of some tests depends on certain preconditions.

### Automated UATs

The automated user acceptance tests of the system are done using Python with Selenium package. The script used for tests is **UAT final_project.py** under **Automated UAT** folder. **UAT document.pdf** under the same folder describes the process of UATs.
